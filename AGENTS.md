# AGENTS.md: working rules for this repo (loaded every session, keep small)

## Non-obvious facts

- Working language is English (code, messages, docs). The owner's family research (fixtures) is Catalan; test *data* may be Catalan, test *names/comments* must not.
- Private real fixtures live OUTSIDE this repo (a local 544-individual / 135-family MyHeritage tree: one cleaned file plus the original export). It contains living people. Never copy tree data into this repo, into issues, or into an agent's context; discuss counts and rule codes only.
- Spec source of truth was pmontp19/gedcom-family-tree#2 (closed on MVP). Both spec audits (5.5.1, 7.0) are done; findings not yet implemented are roadmap, not bugs.
- `action.yml` renders annotations, the job summary and step outputs through `scripts/gh-report.js` (node, present on every GitHub-hosted runner). The zero-dependency rule covers the Rust binary, not the action.
- Release archives ship a `.sha256` since v0.6.0 and `action.yml` requires it by default. The warn-and-continue branch stays reachable through `require-checksum: false`, which is the only way to pin an older release.
- `cargo-llvm-cov` is installed; `cargo-mutants` is not (offline at the time). Mutation testing was manual in a /tmp copy; survivors all have regression tests.

## Constraints (not derivable from code)

- Zero dependencies (measured base speed matters; WASM reuse matters). No clap/serde/wasm-bindgen.
- `src/lib.rs` must stay free of fs/process/env/net so it compiles to `wasm32-unknown-unknown` unchanged. All I/O lives in `src/main.rs`.
- `--fix` only gets safe, invertible repairs, always with `.bak`. Never "fix" semantics (dates, links, merges).
- No global diagnostic cap (a real file has 516 `_UPD` infos); limit output only via `--max`.
- This repo is private. Commit and push after every work unit.
- `CHANGELOG.md` is generated by `scripts/changelog.sh` from the GitHub Releases. Never hand-edit it; the releases are the source of truth.

## Quality gates (run all four)

- `cargo fmt --check`
- `cargo test`
- `cargo clippy --all-targets -- -D warnings` (CI denies warnings; plain `clippy` does not, so use the flag)
- `cargo llvm-cov --summary-only --all-targets` (floor: 96% regions total; raise it when you add code)

The toolchain is pinned in `rust-toolchain.toml` (channel `stable`, components `clippy` + `llvm-tools-preview`, target `wasm32-unknown-unknown`). rustup fetches it automatically, so all four gates give the same answer locally and in CI. Before that pin existed, a laptop on 1.89 and CI on 1.98 disagreed about clippy on the same commit, which is worse than having no gate. Run `rustup update` after a new stable lands.

Also run `cargo check --target wasm32-unknown-unknown` when touching the engine: the WASM build is what the web viewer ships.

## Deferred roadmap (audited, consciously postponed)

- SLGC `FAMC` requirement and other LDS ordinance details beyond `STAT`+`DATE`.
- `W703` ships only the doubled-comma half of its specification. The URL-in-`PLAC` half was dropped so it would not double-report with the core `W401`; the name `malformed-place` still promises more than it does.
- `U501`/`U502` flag the 5.5.1 to 7.0 upgrade path but do not perform it. Converting a tree between versions is a different product, and `--fix` may not touch semantics.
- No plugin runtime, deliberately (RFC 014 section 0.2). Config addresses rules as `<ruleset>/<rule-name>` so external rules could slot into the same namespace if there is ever demand.
