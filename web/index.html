Check your family tree before you import it.

Drop a GEDCOM export and see what Gramps, webtrees, RootsMagic or Geneanet will make of it: broken links, cut-off names, mangled notes, places that will never match anything. Then apply the repairs that are provably safe. Everything runs in this tab.

  • Your file never leaves this browser. It is read, checked and repaired locally; there is no server on the other end.
  • You can verify that in five seconds. This page ships a Content-Security-Policy that forbids every network connection. Open your devtools Network tab: it stays empty while you work.
  • No account, no cookies, no analytics.

Optional extra checks

The default checks are always on. These two rule groups are off by default, exactly like the gedlint.toml presets of the command-line tool; turning one on re-checks the current file.

Findings

Repairs

Safe repairs are exact and reversible: rejoining a character an exporter cut in two, restoring a missing CONT prefix. Those marked needs review guess at formatting and are only applied if you tick them. Your original file is never modified; you download a repaired copy.
